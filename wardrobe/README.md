# خزانتي — منسّق الملابس (تطبيق ويب للآيفون)

صوّر ملابسك، والتطبيق يعرف لون كل قطعة ويسوي لك أوتفتات متناسقة حسب المناسبة والجو.

- كل شي محفوظ **على الجوال بس** (IndexedDB) — ولا صورة ترفع لأي سيرفر.
- يشتغل بدون نت بعد أول فتح (Service Worker).
- يتثبت كتطبيق: سفاري ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## التشغيل
لازم يكون على رابط **HTTPS** (مثلاً GitHub Pages): Settings ← Pages ← Deploy from branch،
وبعدين افتح `https://<اسمك>.github.io/dubli-site/wardrobe/` من سفاري على الآيفون.

## المميزات
- تصوير أو اختيار أكثر من صورة مرة وحدة، واكتشاف اللون تلقائياً (مع إمكانية تعديله).
- أنواع: فوق، تحت، قطعة كاملة (فستان/ثوب/عباية)، جاكيت، حذاء، شنطة، إكسسوار.
- «نسّقلي»: يختار حسب المناسبة والجو، ويقيّم تناسق الألوان (محايد، تدرّج، متجاور، متكامل) ويشرح السبب.
- 🔒 ثبّت قطعة ويكمّل الباقي عليها.
- «بلبسه اليوم» يسجل اللبسة ويتجنب يكرر نفس القطع خلال أيام.
- المفضلة، سجل اللي لبسته، ونسخة احتياطية (تصدير/استرجاع).
