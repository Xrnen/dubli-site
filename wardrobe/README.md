# خزانتي — خزانتك الرقمية (تطبيق ويب للآيفون)

صوّر ملابسك، والتطبيق يشيل الخلفية ويعرف اللون، وينسّق لك أوتفتات، ويخطط لبسك بالتقويم، ويجهز شنطة السفر.

## المميزات
- **إزالة الخلفية بالذكاء الاصطناعي** على الجوال نفسه (مكتبة @imgly/background-removal — تنزل مرة وحدة)، مع طريقة سريعة بديلة بدون نت.
- **تحسين الصورة تلقائياً** (إضاءة وتوازن ألوان) + سطوع يدوي.
- **تعديل يدوي:** امسح أو رجّع أجزاء بإصبعك، تدوير، وتراجع.
- **اكتشاف اللون** الأساسي والثانوي، وتقدر تعدّله.
- **تفاصيل كل قطعة:** الاسم، الماركة، المقاس، السعر، المناسبات، الموسم، تاقات، مفضلة، «بالغسيل».
- **بحث وفلترة** بالنوع واللون والغسيل، وترتيب (الأحدث / الأكثر لبس / الأقل / السعر / اللون).
- **نسّقلي الذكي:** محرك تنسيق مبني على ستايلات التريند (الفخامة الهادئة، تون أون تون، محايد + لمسة لون، ألوان الأرض، أبيض وأسود، قاعدة الساندويتش، سمارت كاجوال، ستريت، دينم × دينم، ألوان جريئة، قطعة وحدة)، مع قواعد الستايلنق (رسمية المناسبة، توازن القصّات، نقشة وحدة، عدد الألوان) والجو الحقيقي، ويتعلّم ذوقك من اللي تحفظه وتلبسه. كل اقتراح يشرح ليش.
- **سوّ أوتفت بنفسك:** كانفس تسحب فيه القطع وتكبّرها بإصبعين وترتّبها قدّام/ورا.
- **التقويم:** خطط لبس كل يوم، أكّد اللي لبسته، وعدّاد اللبسات يتحدث لحاله.
- **السفرات:** تختار المدينة والتواريخ والجو والبرنامج، ويطلع أوتفت لكل يوم بأقل عدد قطع + قائمة شنطة تأشّر عليها.
- **إحصائيات:** قيمة الخزانة، تكلفة كل لبسة، الأكثر لبس، القطع المنسية، توزيع الألوان والأنواع، ونصايح.
- نسخة احتياطية (تصدير/استرجاع)، وضع داكن تلقائي، يشتغل بدون نت.

## التشغيل على الآيفون
1. لازم يكون على رابط **HTTPS**، مثلاً GitHub Pages: Settings ← Pages ← Deploy from branch.
2. افتح `https://<اسمك>.github.io/dubli-site/wardrobe/` من **سفاري**.
3. زر المشاركة ← **«إضافة إلى الشاشة الرئيسية»**.

## الملفات
- `index.html` — الواجهة والتصميم
- `app.js` — كل المنطق (التخزين، إزالة الخلفية، التنسيق، التقويم، السفرات، الإحصائيات)
- `sw.js` — العمل بدون نت
- `manifest.webmanifest`، `icons/`
